# **App Name**: HomeCraft Studio

## Core Features:

- Hero Section Animation: Animated fade-in effect for text and CTAs in the hero section using Framer Motion.
- Trust Highlights Display: Showcase key brand aspects like manufacturing and showrooms with fade-up animations on scroll.
- Services Card Interactions: Interactive service cards with a subtle lift and shadow effect on hover.
- Customization Section: Display manufactured in-house and other options using split layout
- Showroom Location Display: Display location-aware information about the Pune showrooms, along with interactive Call Now and Directions buttons for each.
- Consultation CTA: Persistent call-to-action buttons for immediate contact and design discussions.

## Style Guidelines:

- Background color: #F2EFEA, providing a soft, non-white backdrop.
- Text color: #3A3A3A, offering a dark, readable contrast against the background.
- Accent/CTA color: #BFA980, drawing attention to primary actions with a warm, muted tone.
- Accent Hover: #A8926A to signify button interactivity.
- Headings: 'Inter' (sans-serif) for large headings, providing a clean and modern aesthetic.
- Body: 'Inter' (sans-serif) for body text, ensuring readability and consistency.
- Fade and Translate: Subtle fade and translate animations (300-500ms ease-out) for a smooth user experience.
- Clean Spacing: Maintain clean spacing throughout the home page.
